# 技术讲解与答辩准备 — Sketch2Naiwa

> 用途：技术问答环节（10 分）的准备材料。
> 考察点：① 团队技术理解能力与现场应变；② 规定时间内对关键技术的关键点表达能力。
> 建议用法：先读“一、一分钟总览”练整体表达，再背“二、技术卡片”的加粗关键点，
> 最后用“三、高频问答”互相提问演练。

---

## 一、一分钟总览（练熟这段）

我们做的是 **Sketch2Naiwa**：任何简笔画、照片、视频、甚至手机摄像头实时画面，
都能变成同一个梗角色“奶娃”。

系统里有 **两条产品线**：

1. **极速线（pix2pix）**：用 2358 对“边缘图→奶娃图”从零训练一个条件 GAN，
   推理只要一次前向，**14 毫秒一张**，用它做视频逐帧和实时直播；
2. **精细线（Stable Diffusion）**：用 328 张精选素材训练 **LoRA** 让 SD1.5 学会画这个角色，
   再用 **ControlNet** 输入线稿控制形状、用 **LCM** 蒸馏把采样压到 4~10 步，
   512px 高质量输出。

**技术闭环**：数据自建（GitHub 收集 939 张 → 自动过滤 740 → 人工清洗 328）
→ 两条线训练（pix2pix 240 epoch；LoRA 800 步）→ 评测择优
→ Gradio 应用（画板/图片/视频）+ FastAPI 实时直播（手机 HTTPS 推流）。

## 二、技术卡片（逐项背关键点）

### 卡片 1：pix2pix / 条件 GAN（cGAN）

- **一句话**：配对数据的“图像到图像翻译”，生成器画、判别器挑刺，对抗训练。
- **关键点**：
  - 生成器 **U-Net**：编码-解码 + 跳跃连接，保住输入轮廓的空间结构；
  - 判别器 **PatchGAN**：对图像分成小块分别判真假，关注纹理细节；
  - 损失 = **对抗损失 + L1（λ=100）**：L1 管“像不像”，对抗管“真不真”；
  - 我们的训练：2358 对、batch 8、lr 2e-4 线性衰减、240 epoch、约 4 小时。
- **可能被问**：
  - Q：为什么不用普通 GAN？→ A：普通 GAN 输入是噪声，无法控制输出形状；
    cGAN 把线稿作为条件输入，输出与输入一一对应。
  - Q：为什么要 L1？→ A：只用对抗损失输出会“高清但跑形”，L1 约束像素级接近真值。

### 卡片 2：扩散模型与 Stable Diffusion

- **一句话**：先给图片加噪到纯噪声，再学一个网络把噪声一步步“去”回来。
- **关键点**：
  - 前向过程固定（加噪），**训练目标是预测每一步加的噪声**；
  - **潜空间**：SD 在 VAE 压缩后的 64×64 潜空间上做扩散，比像素空间快 8~10 倍；
  - **文本条件**：CLIP 文本编码器 + **CFG（分类器无关引导）**，
    用正/负提示词的差值放大文本影响；
  - 采样步数原本要 20~50 步，我们靠 LCM 压到 4~10 步。
- **可能被问**：
  - Q：脱离 GPU 能跑吗？→ A：能，但慢；本项目针对 8GB 显存优化（fp16）。

### 卡片 3：LoRA（低秩适配微调）

- **一句话**：不重训大模型，只训练两个小矩阵，让模型学会“新角色”。
- **关键点**：
  - 原理：权重更新分解为 `ΔW = B·A`，A/B 是低秩矩阵，训练参数量 ≈1%（rank=16）；
  - 优点：**省显存、不易灾难性遗忘、可插拔**；一个 12 MB 文件就是一个角色；
  - 推理时可用 **强度系数** 缩放影响（我们扫描出甜点区 w=1.0~1.4）。
- **可能被问**：
  - Q：rank 选多少？→ A：16；社区经验 8~32 之间，小数据集用 16 平衡容量与过拟合。
  - Q：和 DreamBooth 区别？→ A：DreamBooth 会微调部分完整权重、更重；
    LoRA 是低秩补丁，轻量且可组合。

### 卡片 4：ControlNet（结构控制）

- **一句话**：给扩散模型插一条“结构旁路”，让线稿/边缘/姿态控制生成布局。
- **关键点**：
  - 结构：复制 UNet 编码器做可训练副本，用**零卷积（zero conv）** 接入主干；
  - 训练时主干冻结，只训副本 → 不破坏原模型生成能力；
  - 我们用的是 **scribble 涂鸦版** ControlNet，控制图约定为“黑线白底”。
- **可能被问**：
  - Q：为什么不用 img2img？→ A：img2img 会把“不像奶娃”的输入特征带进输出；
    ControlNet 只用输入的结构（边缘），风格完全来自模型，保结构又保角色。

### 卡片 5：LCM / LCM-LoRA（少步采样蒸馏）

- **一句话**：一致性蒸馏让扩散模型从 20+ 步缩到 4 步左右，接近实时。
- **关键点**：
  - 一致性模型要求“同一条噪声轨迹上的任意点去噪到同一张图”；
  - **LCM-LoRA 是可叠加蒸馏适配器**，与角色 LoRA 并联加载（权重 [1.4, 1.0]）；
  - 直播中 guidance 固定 1.0（无 CFG）→ 每步只需一次前向，速度翻倍。
- **可能被问**：
  - Q：步数越少质量越差吗？→ A：4~10 步内质量变化小，2 步以内开始崩；
    我们按场景选 3~10 步。

### 卡片 6：HED 边缘检测

- **一句话**：用学习式（神经网络）边缘检测替代 Canny，提取更符合作画习惯的轮廓。
- **关键点**：
  - HED = Holistically-Nested Edge Detection，多尺度侧输出融合；
  - 对卡通图的轮廓响应比 Canny 干净、不需要手调双阈值；
  - 我们用它把训练图转成边缘图建 pix2pix 配对集，也用于生产路径提取线稿。
- **可能被问**：
  - Q：为什么不用 Canny？→ A：Canny 阈值敏感、对彩色卡通图边缘断续；
    HED 是端到端学习的语义边缘。

### 卡片 7：U²-Net / rembg（抠图）

- **一句话**：显著性检测模型把主体从照片中抠出来，贴白底再进生成管线。
- **关键点**：
  - U²-Net 是嵌套 U 结构，预测主体显著图（不是按类别，而是“最显眼物体”）；
  - 抠图后 alpha 硬阈值 + 贴白底，保证与训练数据（白底角色）同分布。

### 卡片 8：训练技巧清单

- **cosine 学习率 + warmup**：预热 80 步防早期发散，余弦退火收尾稳定；
- **SNR-gamma（min-SNR 加权）5.0**：按信噪比给时间步加权，加速收敛；
- **梯度累积**：batch=1 × 累积 8 ≈ 等效 batch 8，显存不够时的标准做法；
- **梯度检查点**：用计算换显存，训练峰值压到 3.3 GB；
- **fp16 混合精度**：推理/训练都省一半显存。

### 卡片 9：系统与工程

- **Gradio**：快速搭交互界面；**队列机制** 处理课堂十几人并发（单卡串行排队）；
- **实时直播**：手机浏览器 `getUserMedia` 采集 → HTTPS + WebSocket 推 JPEG →
  PC GPU 逐帧生成 → 写文件供电脑端大屏显示；帧丢弃策略“latest-wins”防积压；
- **TAESD 微型 VAE**：解码速度大幅提升，换画质换帧率，直播专用；
- **自签证书**：手机访问必须 HTTPS，脚本首次运行自动生成。

### 卡片 10：评估方法

- **pix2pix**：测试集 L1（越低越好）+ 逐 epoch 生成网格目检
  （发现并弃用有棋盘格伪影的 BN 震荡 checkpoint）；
- **LoRA**：多 checkpoint 生成对比 + LoRA 权重扫描；
- **原则**：GAN 的 loss 曲线无参考意义，必须“出图看效果”。

## 三、高频问答（互相演练）

1. **为什么不直接用一个大模型（如 SDXL）？**
   → 8GB 显存 + 实时性约束；双产品线组合已覆盖“秒出”和“精细”两类需求，
   通用大模型不认识我们的小众角色，仍需微调。

2. **这个模型“学会”角色的证据是什么？**
   → 纯文本生成（无控制图）也能稳定出同一角色（`v3_txt2img.png`）；
   ControlNet 输入任意新形状（靴子/蘑菇/瓶盖）都能输出“奶娃化的该形状”。

3. **为什么照片输入会“抽象崩坏”？**
   → 训练分布是白底卡通角色，真实照片是域外输入；我们通过抠图+边缘
   把照片“翻译”进训练域。崩坏本身是模型的域外泛化边界。

4. **脸部是画出来的还是模型补的？**
   → 都可以：画了眼睛嘴就渲染你的版本；不画也能补，
   因为 v3 的文本描述里显式写了脸部特征，模型按“脸在身体上部”的先验自动补。

5. **为什么输出背景是白色？**
   → 训练数据全是白底；v3 数据还做了 80% 留白，让模型学会“主体居中四周留白”。

6. **实时直播能到多少帧？**
   → 纯 pix2pix 管线 60+ fps；LoRA 直播 3~4 步 LCM + TAESD 约 3~8 fps；
   帧率受无线网络与手机端推流影响。

7. **训练用什么数据量级？会不会过拟合？**
   → 328 张精选素材 + 9 倍增强；通过 checkpoint 评估择优控制过拟合
   （800 步版本已过拟合，选了 200 步）。

8. **怎么防止模型输出盗图/抄袭？**
   → 训练素材为开源梗图二次创作；生成结果为模型学到的风格分布采样，
   不复制训练图（生成与任何单张训练图的相似度很低）。

9. **两条产品线的模型架构一样吗？**
   → 完全不同：pix2pix 是 CNN 的 GAN（U-Net + PatchGAN）；
   LoRA 线是扩散模型（UNet+VAE+CLIP）+ LoRA/ControlNet/LCM 适配器。

10. **如果给更多显存和时间，下一步做什么？**
    → 提高分辨率（512→768）、换更强基座（SDXL/FLUX-LoRA）、
    引入视频扩散（时序一致）、把像素级 L1 换成感知损失评估。

## 四、现场演示流程建议（3 分钟版）

1. **一句话开场**：画什么都能变奶娃（展示 showcase 图）。
2. **演示 1（30s）**：演示版画板随手画个圈 → 点生成 → 出角色
   （强调：没画五官也能长脸 = 隐式加脸）。
3. **演示 2（30s）**：切换模型，同一张画对比 pix2pix（秒出）和 LoRA（精细），
   解释两条产品线取舍。
4. **演示 3（30s）**：上传一张照片 → 抠图 → 边缘 → 输出该形状的奶娃
   （靴子/猫示例）。
5. **演示 4（40s）**：手机现场直播：拍台下同学/教室 → 大屏实时变奶娃。
6. **收尾（10s）**：全流程在本机 8GB 笔记本完成，数据自建、双线模型、可离线运行。

备选话术：如果网络/手机出问题，用录屏或“随机奶娃轮廓”按钮兜底。
